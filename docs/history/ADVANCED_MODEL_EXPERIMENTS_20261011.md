# FlashPPI 数学建模方案：诊断与固定预算试验

日期：2026-10-11。承接 `MODEL_IMPROVEMENT_PLAN_20261011.md`，本轮只使用 train 和固定 val 决策。

## 当前训练判断

step 1100 的 val CLIP AP / 接触 P@K / 互作 AP 为 0.750796 / 0.254941 / 0.578818。
接触指标仍在改善，CLIP 相对 step 1000 小幅回落。第二个 epoch 刚开始，证据不足以提前停止，保留原 2150-step 预算。
不以已观察过的 E. coli 或 RF2-PPI test 调参。新实验固定使用不可变的 `best_step_001100` 快照。

## 第一阶段：诊断

- 合并后的权重插值：官方权重到 step 1100，系数固定为 0、0.25、0.5、0.75、1。完整 4200 对互作 val 和 500 对结构 val，记录 CLIP AP、接触 P@K、互作 AP及 1:1000 加权 AP。
- 链交换：完整 val 交换 A/B 后重评，另固定随机种子选择 64 对结构比较接触图。保持已有预测公式；不把两个方向融合成新的官方指标。
- 共享 LoRA 梯度：8 个独立训练批次，记录两个任务的梯度范数、夹角和实际损失权重后的范数。诊断预算为 batch 64、microbatch 8、界面长度 256；它不等于原 1024/16/512 配置的梯度分布，不能单独证明正式训练存在冲突。

## 第二阶段：同条件 CLIP 小试验

配置：`configs_train/clip_improvement_pilot_v1.json`。三个独立组均从 step 1100 初始化，冻结骨干和接触头，仅更新 CLIP 头及温度。

- 从 train 聚类采样 2048 个不同无序序列对；两链长度 32–512，全长输入，均有有效接触。相同固定样本服务于全部组。
- batch 1024，100 步，学习率 1e-5，10 步 warmup，25 步验证一次。此为有限样本 pilot，不代表全量训练收益。
- 普通 CLIP 对照；CLIP + 接触教师排序蒸馏；CLIP + sampled top-k 负例排序损失。辅助权重均固定 0.1，不混合两种改动。
- 每个方向固定 1 个真实正对、4 个 CLIP 难候选和 3 个随机候选；依据全部训练记录的双向同源簇互作键屏蔽已知正例，排除相同序列自配对。缺少训练集可靠物种映射，候选保持原训练的混合物种范围，必须单独披露这一限制。
- 蒸馏温度 2；仅使用教师把真实正对排第一的候选组。尾部损失使用教师接触分数低于 0.1 的候选中最大的两个排序损失。这些过滤是启发式，不能证明未标注负例真实为阴性。
- val CLIP AP 是预先指定的选模指标，加权 AP 为补充；保留 best 和 last、训练状态、样本标识、数据与代码指纹。骨干和接触头逐字节验证未变。

## 后续推进门槛

交换诊断完成后追加接触头独立对照：固定同一个 step 1100 编码器和 CLIP 头，复用上述 2048 正对与候选清单，比较 focal 对照、focal + 交换一致性、focal + 负例尾部排序。配置为 `contact_improvement_pilot_v1.json`：每步 16 个正对，microbatch 2，每正对 1 个难候选和 1 个随机候选，100 步，学习率 1e-5，10 步 warmup，50 步验证一次。交换损失权重 1，尾部排序权重 0.02。接触 P@K 是预先指定的主选模指标，互作及加权 AP 同时报告。

该对照由完整 val 的链交换差异触发，不使用 test；依然是固定预算的小试验，不与原全量 LoRA 直接比较训练效率。

只将相对同预算对照有改善、且没有明显辅助指标退化的方向推进到更大训练集和多种子复验。单个小 val 上的涨点不视为显著性结论。先完成这些比较，再确定是否投入多界面表示、结构教师或更大范围的联合 LoRA。

当前 4119 个 val 负例不足以精确评估极低 FPR；1:1000 加权不会增加独立负例数。正式低假阳性研究需要另行固定更充分的验证负例背景，同时保留当前 val。
