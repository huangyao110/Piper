# 固定 DDI 结构验证集 v1

2026-10-13 完成，共 **677 对 DDI**，来自 677 个不同母蛋白、677 个不同无序域簇对，包含 1,354 条不同域序列。TED 来源 661 对，CongLab 来源 16 对。所有样本原本就在首次 DDI 训练前的同源排除集合中；选择过程没有使用模型预测。

## 文件与用途

- `data/ddi_validation_v1/validation.parquet`：最终数据，约 2.17 MiB，包含序列、接触索引、有效掩码和 float64 坐标，可直接重建距离矩阵。
- `pairs.tsv`：便于查看的名单、来源、母蛋白、域簇、长度和接触数。
- `references.parquet`：原始分片、行组和行偏移。
- `manifest.json`、`inventory.json`、`homology_audit.json`：过滤统计、来源和文件哈希。
- `config.json`、`build_ddi_validation.py`：固定参数和脚本快照；运行入口为仓库的 `tools/build_ddi_validation.py`。

这是**正例结构验证集**，适合评估接触 P@K（K 为真实接触数）、残基对 AP 和距离交叉熵；不能直接计算需要互作负例的 CLIP AP。评估使用完整域序列，关闭随机 mask 和裁剪。域长度为 30–409，长度中位数 116；接触密度中位数约 1.03%。

## 筛选过程

| 阶段 | 剩余 DDI 对数 |
| --- | ---: |
| 原始 DDI | 10,674,581 |
| 原先因 holdout 同源而排除 | 2,638,249 |
| 与现有 PPI val 相关、无 RF2 相关域簇 | 86,949 |
| 两条域的 70% 序列簇均未进入实际训练 | 62,418 |
| 长度与完整坐标条件合格 | 62,346 |
| 排除训练中出现的母蛋白 | 57,154 |
| 每母蛋白、每无序域簇对各取一对 | 39,066 |
| 两方向实际训练集同源检查后 | 708 |
| 直接排除 RF2-PPI 同源项后 | **677** |

固定种子为 `20261013`。对实际训练中的 **13,730,481 条不同域序列**使用 MMseqs2 18.8cc5c：一致性 ≥30%，覆盖任一对齐域 ≥80% 时排除候选整对，分别检查候选域覆盖和训练域覆盖。另以 RF2 的 17,281 条不同蛋白序列直接检索候选域，要求覆盖候选 DDI 域 ≥80%，不要求覆盖完整 RF2 蛋白。敏感度 7.5，E-value ≤0.001，具体命令已保留。

首次 12,000 对候选只通过 214 对，因此扩展到了全部去冗余候选；阈值没有放宽。最终保留全部 677 对，不为达到原拟定的 1,000 对而继续扩大范围。初次筛选记录在 `initial_screening/`。

## 核验与边界

677 对均通过坐标、接触标签重建、序列内容哈希、ESMC 残基/token 对齐和 Parquet 读回核验。接触遵循源数据 Cβ／甘氨酸 Cα 距离严格小于 12 Å，距离分箱能还原相同二值标签。57 个保留产物的哈希已逐一核验；6 项回归检查通过，包括真实 MMseqs 长短序列包含关系的两个覆盖方向。

相对于实际训练索引，精确域序列、70% 域簇和母蛋白均无重叠；按本次 MMseqs 检索规则没有接受的训练或 RF2 同源命中。启发式搜索不能证明完全不存在远缘同源，也没有要求结构折叠互不相同。该集合按构建方式与现有 PPI val 相关，不是从所有 DDI 随机抽出的独立样本。

坐标来自预测结构；本次坐标发布不包含置信度字段，未额外应用 pLDDT／PAE 过滤。未审计官方 ESMC 预训练是否接触过这些序列。

原始数据库、训练索引、现有 PPI val、RF2 test 和后台训练选择标准均未修改。新集合尚未接入后台训练的验证流程。构建用的大型临时数据库已清理，最终数据和审计记录保留。

## 复现

日常评估直接读取最终 Parquet，无需重新搜索。需要重建时，复制 `configs_data/ddi_validation_v1.json`，把 `output` 改为仓库 `data/` 下的新目录，再运行：

```bash
.venv/server/bin/python tools/build_ddi_validation.py --config 新配置.json --stage all
.venv/server/bin/python tests/test_ddi_validation_builder.py
```

冻结的原输出不会被脚本静默覆盖。
