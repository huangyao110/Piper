# CLIP residue pooling gate: study v1

研究问题：**CLIP 残基门控是否在未见结构中偏重互作相关残基，以及这种偏重是否帮助 CLIP 判断互作？**

本阶段使用固定 val 做探索，不将它称为独立验证集上的新发现。后续确认性研究
需要事先锁定、未用于反复调参的独立面板。这里不改动已有 train/val/test 成员、
去重、同源过滤、聚类或接触定义，也不生成新的训练数据。

## 对象与解释边界

只研究 `head_q.residue_pool`、`head_k.residue_pool`，分别报告。不研究 concat 的
通道门控、融合系数或主干 attention。两个分支各自给定一条完整序列即可确定门控，
不以互作伙伴为输入。因此可以检验界面倾向，不能把它解释为针对某个伙伴的接触图。

对第 i 个有效残基，保存：

- `g_i = sigmoid(MLP(LayerNorm(h_i)))`：原始门控。
- `a_i = g_i / sum_j(g_j)`：实际池化比例。
- `r_i = L * a_i`：长度归一化权重；均匀池化为 1。

原始 gate 同时变大但比例不变，不意味着选择性变强。先看有效残基比例
`1 / (L * sum(a_i²))`、归一化熵和分位数，再解释生物学关联。
上下文 embedding 可以编码其他位置的信息，所以位置权重不是该位置的因果贡献。
CLIP gate 没有直接接触监督，但共享 encoder 受到接触 loss 训练；不能宣称完全无监督涌现。

## 固定比较与数据

- `before_1616`：扩充数据前 B 模型最终 checkpoint。
- `after_2182`：扩充后已正式测试的 checkpoint。
- 原结构 val：100 个结构；使用源 `contacts` 与 `valid1/valid2`。
- 原互作 val：228 条已标注互作，25 正、203 负；保留原方向。
- checkpoint、源文件、输入数据的路径与 SHA256 记入 manifest。

界面是源标签的任一跨链接触位置，定义为 **Cβ < 12 Å，Gly 使用 CA**，不是 8 Å
接触，也不是实验结合热点。缺失坐标不能当成阴性；实现会保守地将不可确定的位置
标为 unknown。分析标签是源记录的派生视图，不会写回数据。

同一序列只编码一次，但保留其在不同结构/伙伴中的界面标签。先计算每条结构链的
指标，再对同一序列等权平均。再将共享序列、原有序列簇和同一复合物连成依赖块，
报告块等权均值及块 bootstrap 区间，避免把残基或重复结构视为独立重复。
这些原有簇不能保证彻底消除远同源关系；块数太少时区间不可靠。

## 三个检验

1. **门控是否形成选择性。** 观察 r 分布、有效残基比例、q/k 一致性和两个
   checkpoint 的排序稳定性。均匀门控应给出有效比例 1、界面富集 1。
2. **高权重是否富集界面。** 每条链报告 AP、AUROC、Top 10% 界面富集。
   AP 同时报告本链界面占比；Top 阈值并列时用随机并列顺序的期望，不能按残基位置
   随意打破并列。首轮用同氨基酸内置换控制组成偏好；有 SASA 注释后增加
   AA × 10 个固定暴露度分箱的控制。保守性先做链内 Spearman，再按结构、MSA
   质量分层检查。没有注释时明确写“尚未检验”。
3. **门控位置是否帮助 CLIP。** 同一次完整序列编码得到的 h 固定，比较原门控、
   均匀池化、在有效残基中打乱门控位置（保留权重分布和总量，20 个固定随机种子）。
   分别干预 q、k、双方。报告同一已标注互作面板的 AP/AUROC 和配对分数变化。
   只有同一个 query 有已标注正负候选时才报告候选排名；不将其他未知互作当负例。
   这是推理时依赖检验，不等价于从头训练无门控模型的消融。

均匀/置换操作只作用于 CLIP 池化，不改 embedding、不改 concat。若该操作被用来
解释 concat 接触预测变化，说明实验对象已混淆，应停止解释并检查实现。

## 如何得出结论

| 观察 | 支持的解释 |
|---|---|
| gate 接近均匀 | 目前证据不支持强残基选择性 |
| 界面富集，但 AA/SASA 控制后消失 | 可能主要识别组成或暴露特征 |
| 界面富集，但打乱后 CLIP 基本不变 | 有位置关联，预测依赖证据不足 |
| 打乱后 CLIP 下降，但不富集已知界面 | gate 可能使用其他序列特征，不能直接叫界面机制 |
| 控制后仍富集，且打乱会降低 CLIP | 更支持具有功能关联的选择；仍非生物因果证明 |

两个 checkpoint 同时存在训练步数、扩充数据、采样、数值精度等差异；不能将差异
全归因于新增数据。后续如需证明结合热点，应有独立突变/结合能证据。

## 实现与验证

单序列全长 eval，无随机裁剪或残基 masking，沿用正式评估 FP16 autocast。
门控重算必须逐值等于原生 head 输出。无效 padding 在 LayerNorm 前清零；打乱
只触及有效残基。门控表一行对应准确的全长序列位置，不使用 patch 标签。

CPU 回归覆盖原生公式回放、NaN padding、归一化、置换、未知标签、并列富集、
重复记录、注释映射和输出目录边界。真实模型推理需要空闲 GPU，脚本检测到占用会
直接退出，不触碰训练。只读 checkpoint/预训练权重；小型模型代码复制到本目录并
记录来源，未被历史 manifest 覆盖的依赖明确标记 fallback。

方法背景：[BERTology Meets Biology](https://arxiv.org/abs/2006.15222)、
[Attention is not Explanation](https://aclanthology.org/N19-1357/) 提供序列表示及
解释验证思路；后者讨论 attention，不能直接当作本模型 gate 无解释性的证据。
[SKEMPI 2.0](https://pmc.ncbi.nlm.nih.gov/articles/PMC6361233/) 是后续独立突变效应验证的候选资源。
